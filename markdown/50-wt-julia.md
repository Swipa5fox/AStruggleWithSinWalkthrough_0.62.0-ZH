[市长大宅](#wt-mansion)中的女仆。

    1. 攻略 Julia 有 2 条路线：
    2. 通过与 [Yasmine](#wt-yasmine) 做爱并舔食精液来腐化 Julia，你也可以通过调换仆人房间里的酒来腐化她。

    3. 和她聊天，等剧情推进后再向 Giron 请求娶她。

1. 如果你当着她的面操 Yasmine，这会在厨房触发与她的另一段对话（前提是你与她处于恋爱路线），之后下次再发生这种事时她就会加入。如果你还没有通过约会的方式与她做爱，这样做会夺走她的初夜。

2. 如果你已经告诉 Julia 你对她不感兴趣，但之后又向她的父亲请求娶她，你就会回到与她的恋爱路线。

3. 在两条路线上，你现在都可以约她出去。如果你已经翻修了房子并订做了一张更大的床，你就可以把 Julia 请进你的房间。如果她的好感度达到 10+，她就会与主角发生性关系（如果是第一次，主角会夺走她的初夜）。如果你第二次邀请她，会解锁另一个动画，而且她会留宿过夜。

4. 再次与她交谈，请求在厨房来一发速战速决（恋爱路线同样可用）。

5. （NTR）如果你现在告诉她，她应该有所改进，她就会考虑借助管家的帮助来做到这一点。如果她的堕落值达到 C5+，她就会在午夜与管家做爱。如果你随后闯入并等他们发现你（未伪装），你就会被逮捕，但这也会让你在厨房与 Julia 开启新的对话。你现在可以继续这条路线。下次你撞见他们时，管家会告诉你，他会为你进一步调教她。

6. 无论你是否选择了 NTR 路线（6.），要触发此事件，你都必须先完成第 3 步或第 4 步：如果你已经把 John 的任务推进到 Julia 在你拜访市长时端茶给他那一步（即你可以派人去矿场那一步），她就会告诉你，她的父亲想见她。

7. 使用 Giron 书房里的书架，在他身处其中时选择"躲藏并偷听"。Julia 随后会进来，两人会进行一段简短的对话。

8. 在厨房与 Julia 交谈。这也会改变她与 Yasmine 在钢琴旁的那场戏。
