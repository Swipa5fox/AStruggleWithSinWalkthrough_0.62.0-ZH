# Ayita（阿伊塔）

[Rumah 村](#wt-rumah)的舞者。

在你把肉带给 Palak 后，他会再次要求与你交谈。他会告诉你他爱上了 Ayita，希望她能注意到他。现在有 3 个选项可以推进剧情（建议先存档）：

    1. 派他去执行一个危险的任务：他会离开村子。跟在他后面出去，在 Raaisha 袭击你的那块石头附近搜索踪迹。
    2. 凭借你的狩猎技能，你会找到通往一个洞穴的踪迹，洞穴里你需要与一头熊战斗。如果快速与 Palak 的尸体互动然后离开洞穴，可以跳过战斗。

    3. 进入 Rumah 时，向一名守卫通报 Palak 已死。

    4. 现在与 Ayita 交谈，告诉她 Palak 的遭遇。

    5. 之后再与她交谈（参见恋爱路线）。

1. 他会请求你演示如何与 Ayita 交谈，好让他向你学习。这将开启 netori（逆 NTR）恋爱路线。（参见恋爱路线。）

2. **NTR 路线：**给他一瓶精酿酒（Cumwine）。傍晚他坐在火边时再次与他交谈。重复 3 次后，Ayita 的堕落值会足够触发一个小场景。
 **这会把其他选项全部锁死。此后想要与 Ayita 有更多互动，唯一的方法就是把 Rumah 的女人宣布为全村公用。**

### 恋爱路线：

Ayita 是个物质女。可怜的 Palak 对此一无所知。她无法产生真正的感情（至少目前如此）。也许主角将来能改变这一点。目前你可以通过送她珠宝（胸针、戒指、项链）或酒瓶来提升她的好感度。每送一件礼物，你都能从她那里获得 1 点恩惠（favor）。

1. 现在每晚可以请她跳一次舞。你需要好感度达到 2+。

2. 再次与她跳舞，现在你多了一个可以掏出阴茎的选项。

3. 第二天再与她跳舞时，掏出阴茎后你可以选择和她做爱（在此之前你需要连续送她 2 件礼物）。

4. 如果她的好感度低于 11，在她提供更多互动之前，总会先索要一件礼物。（用礼物只能把她的好感度刷到 10。要进一步提升，需要先和她跳舞再做爱，而跳舞做爱需要恩惠，所以要在两次之间不跳舞的情况下连续送她 2 件礼物。）好感度超过 11 之后，你就不用再送她任何东西了。

5. 在她与你做爱 5 次之后，早上她坐在火边时你也可以请求与她做爱。现在还会多出第二种可切换的体位。

6. 6. 傍晚坐在火边（互动点），如果 Ayita 正在裸舞，你可以把她叫过来进一步互动。如果你走酋长路线且已关闭共享（sharing）选项，现在可以选"就一起待一会儿"来加深与她的关系——一开始这可能会消耗你与她的恩惠点数（通过送礼物来积攒）。——重复这一动作，同时记得提升她的好感度。当她的好感度达到 16+ 时，可以触发该事件的最终阶段，并把她收为你的 wanita（专属女人）。如果选择这样做，第二天早上与她交谈时可以开始举行认领仪式。之后还可以让她受孕。（目前没有怀孕阶段。）

### NTR 路线：

这条路线很好解释。根据你的路线（Dazan/酋长）不同，你可以与 Umin 交谈，让村里的所有女人都可供使用。在 Dazan 路线上这是默认设定。现在你可以和 Ayita 在火边跳舞并与她做爱。

### 与 Hiba 的三人行：

在火边把她叫过来且 Hiba 就在你旁边时，你可以让 Ayita 过去与 Hiba 来一场三人行场景。这需要 Hiba 是你的 wanita，或者 Rumah 已开启共享（sharing）选项。
