# Rumah 村

跟随 [Tia](#wt-tia) 的任务线来到这里。

1. **Hiba**：你可以给她喝精酒来腐化她——做法是：当你身上还有一小瓶精液时，在物品栏里对酒使用它（见 [Lucius](#wt-lucius) 的任务）。
- 这样做 5 次之后（每次之间必须隔一天），她会想离开她的丈夫。此时 **Tia** 的堕落值必须达到 C11+，否则你得把 **Tia** 留在她母亲那里或小屋里。然后你必须在一场决斗中战胜她丈夫（他还会掉落一件可以给 **Tia** 装备的皮甲）。

- 在与 **Hiba** 的后续场景中，**Tia** 会根据她的 C（堕落值）对你与 **Hiba** 在一起作出反应。这也会反映在你小屋里与 **Tia** 的性爱场景中。

- 如果你 3 天不与 **Hiba** 做爱，她会在早上你睡在小屋里时来拜访你。

2. **Ayita**：在你带给 **Palak** 他要求的肉之后，再次与他交谈。他会告诉你他爱上了 **Ayita**，希望她能注意到他。更多信息见 [Ayita](#wt-ayita)。

3. **Umin**：给他木材之后再次与他交谈。再给他 5 块古木（Elderwood），他会给你一把新弓。
