# Agatha（阿加莎）

Parakis 的大祭司，[Bridget](#wt-bridget) 的母亲。作为 [修道院](#wt-monastery) 的一部分解锁。

1. 在 **Bridget** 请你帮她找日记之后，溜进她的房间检查她的床，然后你可以试着伸手到她枕头下面，为此你必须通过一次敏捷检定（你可以故意选择快速完成的选项来失败）。

    1. 根据你是否成功，**Agatha** 会有不同的结果。
    2. 你成功了，然后勒索她（**Agatha** 顺从路线）。

    3. 你成功了，然后索取金钱（与 **Agatha** 不再有内容）。

    4. 你成功了，然后不收钱、把书还给她（恋爱路线）。

    5. 你失败了，并向她臣服（**Agatha** 支配路线）。

    6. 你失败了，但没有臣服（意味着 **Bridget** 将嫁给 **Jorge**）——（恋爱路线）。

2. 每条路线都有不同的对话和略有不同的动画。她也可以被腐化：当她的堕落值达到 C5+ 时，她会在午夜开始自慰。（所以最好先存档，再选择你偏好的路线）。

3. 如果你后来决定指控 **Adson**（只有在你拿到了她的日记，并且还在你的房间里找到了给 **Matthias** 的信时才可能），她会非常愤怒，但如果你勒索她，她仍会继续做你的仆人。
